Supporting [CRY] Cryptography

W77Q provides the fundamental contribution to the device CRY.

Secure monotonic counters ( for implementing rollback protection )

JDEC RPMC standard

Some W77Q chips support JDEC RPMC standard, same way as W25R flash series. Such counters do not take flash volume.

Secure MCs ( Monotonic Counters ) on flash

All W77Q chips can support secure monotonic counters kept on secure flash, thus obtaining protected counters. Such counters will reside on flash and are as flexible as W77Q's policy. Their number is also not limited to 4 like it is usually implemented in JDEC RPMC.

C code implementation

Monotonic counters sample is split in two phases - manufacture and field. During manufacture flash sections are configured with different policies and monotonic counters are formatted on it, during field phase we show how the counters are used.
