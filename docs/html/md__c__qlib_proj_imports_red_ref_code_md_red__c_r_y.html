Supporting [CRY] Cryptography

W77Q provides fundamental support for the device's cryptography requirements (CRY).

Secure Monotonic Counters (for Rollback Protection)

JEDEC RPMC standard

Some W77Q devices support the JEDEC RPMC standard, as do devices in the W25R flash series. These counters do not consume flash density.

Secure Monotonic Counters on Flash

All W77Q devices support secure monotonic counters stored in secure flash. These counters are protected and governed by the W77Q access policy. Their number is not limited to four, unlike typical JEDEC RPMC implementations.

C code implementation

The monotonic-counter sample has two phases: manufacturing and field use. During manufacturing, flash sections are configured with different policies and the monotonic counters are formatted. During field use, the sample demonstrates how to use the counters.
