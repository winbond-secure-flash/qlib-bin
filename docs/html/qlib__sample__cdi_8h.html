◆ QLIB_SAMPLE_DiceAttestation()

QLIB_STATUS_T QLIB_SAMPLE_DiceAttestation ( void *  userData_pv,
bool  runFieldFlow_b 
)

This function demonstrates cdi value retrieval through the boot chain consisted of 3 boot stages.

The function run also the initialization sequence. The sample demonstrates the "Extending Chain Of Trust" secure flow described in W77Q AS v0.93 revA section from January 17,2021 (section 8.6.3)

Parameters
[in]userData_pvPointer to data associated with this qlib instance.
[in]runFieldFlow_bif true, the field flow is run (assuming flash is configured with sections 0,1,2). if false, the manufacture (configuration) flow is run to configure the flash Note, that after flash configuration a HW reset to flash must occur before running the CDI field flow
Returns
QLIB_STATUS__OK if no error occurred, QLIB_STATUS__(ERROR) otherwise
