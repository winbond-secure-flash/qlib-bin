QLIB usage

While using QLIB note the following:

Mixed mode - standard flash driver for standard flash operations and QLIB for secure flash operations

W77Q 16Mb to 128Mb flash supports all the standard flash instructions that are supported by W25Q. W77Q/T 256Mb to 1Gb supports most of standard instructions that are supported by W25Q and W35T. The user should use the standard flash driver as is to execute standard flash instructions on W77Q/T. When secure operations are required, the user needs to use QLIB. If the user's code contains both standard flash instructions and secure commands, it is possible to operate both the standard flash driver and QLIB. Working in mixed mode requires:

  1. When executing standard flash instructions, errors resulting from the execution of standard flash instructions are registered in the SSR. In order to clear the errors, the user must call QLIB_GetStatus after each standard instruction or right before any secure command.
  2. When configuring the SPI interface using the standard flash driver (e.g change of bus mode or address mode), the user must use the QLIB_NotifyInterface to notify QLIB of the new SPI state.

Initial state

Note that QLIB assumes that the flash chip is not in bypass-mode. It is the user's responsibility to exit bypass mode before using QLIB. To exit bypass mode - input FFFFh/FFFFFh on IO0 for the next instruction (16/20 clocks).

Some of W77Q/T commands are blocking commands - meaning the flash becomes busy and inaccessible during their execution.
