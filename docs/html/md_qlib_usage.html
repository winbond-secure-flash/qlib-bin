QLIB Library User Guide
QLIB usage

Keep the following points in mind when using QLIB:

Mixed mode - standard flash driver for standard flash operations and QLIB for secure flash operations

W77Q-JW, W77Q-JV and W77Q-RV devices support all standard flash instructions supported by W25Q. W77Q/T-NW support most standard instructions supported by W25Q and W35T. Use the standard flash driver unchanged to execute standard flash instructions on W77Q/T. Use QLIB for secure operations. If an application uses both standard flash instructions and secure commands, it can use both the standard flash driver and QLIB. Working in mixed mode requires:

  1. When standard flash instructions are executed, any resulting errors are recorded in the SSR. To clear these errors, call QLIB_GetStatus after each standard instruction or immediately before a secure command.
  2. When changing the SPI interface configuration using the standard flash driver—for example, changing the bus mode or address mode—call QLIB_NotifyInterface to notify QLIB of the new SPI state.

Initial state

QLIB assumes that the W77Q/T device is not in bypass mode. Exit bypass mode before using QLIB. To exit bypass mode, input FFFFh/FFFFFh on IO0 for the next instruction (16/20 clocks).

Some W77Q/T commands are blocking: the flash becomes busy and inaccessible while they execute.
