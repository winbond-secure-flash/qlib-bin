Qlib library interfaces W77Q flash via spi callback that host needs to implement. Its core functionality:

  • Sending a command (cmdSize bytes from dataOutStream).
  • Sending an address (addressSize bytes from dataOutStream + cmdSize).
  • Sending data (dataOutSize bytes from dataOutStream + cmdSize + addressSize).
  • Clocking out dummy cycles (dummyCycles).
  • Reading data (dataInSize bytes into dataIn).

This needs to happen atomically, meaning the Chip Select (CS) line should remain asserted throughout the entire sequence (write phases, dummy cycles, read phase).

Here we show how this callback is implemented in different sw environment ( operating systems ) with explanations and ready C code for your reference.
