◆ QLIB_SAMPLE_CheckDigestIntegrity_L()

static QLIB_STATUS_T QLIB_SAMPLE_CheckDigestIntegrity_L ( QLIB_CONTEXT_T *  qlibContext,
bool  expectPass_b 
)
static

Opens a restricted session on the digest section and checks its digest integrity.

Two methods are available, selected at compile time via QLIB_SAMPLE_INTEGRITY_USE_GET_SIGNED_DATA:

  • Method 0 (default): QLIB_CheckIntegrity - the device verifies the digest against the configured value and returns an error status directly on mismatch.
  • Method 1: QLIB_GetSignedData - retrieves the current section digest as raw bytes and compares them manually against QLIB_SAMPLE_INTEGRITY_DIGEST_EXPECTED. QLIB_GetSignedData always returns QLIB_STATUS__OK regardless of data correctness; integrity is determined by the comparison.
Parameters
[in]qlibContextQLIB internal state
[in]expectPass_bIf true, check is expected to pass; if false, check is expected to fail
Returns
QLIB_STATUS__OK if the integrity result matched expectPass_b, QLIB_STATUS__(ERROR) otherwise
