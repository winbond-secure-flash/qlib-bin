◆ QLIB_SAFETY_Init()

QLIB_API QLIB_STATUS_T QLIB_SAFETY_Init ( QLIB_CONTEXT_T *  qlibContext,
QLIB_BUS_FORMAT_T  busFormat,
const KEY_T  key,
uint32_t  qlibSafetyVersion_u32 
)

This function performs QLIB library initialization and initializes the communication with the W77Q/T.

The initialized state is contained in qlibContext. This initialization must be performed before usage of other safety QLIB functions.

Parameters
[out]qlibContextQLIB internal state
[in]busFormatFlash interface format, consists of bus mode and dtr.
[in]keyValue of full access key for section 0, array of 4 uint32_t (total of 128 bits).
NULL or zero value key is not supported.
[in]qlibSafetyVersion_u32QLIB safety version to verify. Must be the same as the current QLIB safety version. 0x00010000 -> 0.1.0.0
Returns
QLIB_STATUS__OK = 0 - no error occurred
QLIB_STATUS__INVALID_PARAMETER - qlibContext is NULL
QLIB_STATUS__INVALID_PARAMETER - key is NULL or zero value key
QLIB_STATUS__INVALID_PARAMETER - qlibSafetyVersion_u32 does not match the current QLIB safety version
QLIB_STATUS__DEVICE_SYSTEM_ERR - One of the sections has wrong configuration (e.g rollback and size is not correct)
QLIB_STATUS__PARAMETER_OUT_OF_RANGE - busFormat is QLIB_BUS_MODE_4_4_4 and QLIB_SUPPORT_QPI is not defined
QLIB_STATUS__(ERROR) - Other error
Examples
qlib_sample_safety.c.

◆ QLIB_SAFETY_ConfigDevice()

QLIB_API QLIB_STATUS_T QLIB_SAFETY_ConfigDevice ( QLIB_CONTEXT_T *  qlibContext,
KEY_T  masterKey,
KEY_T  sectionKey 
)

This function deploys new security configuration to the flash, and verifies the configuration.

This function should be used on a clean formatted flash in case it configures the keys. The flash is configured with a single section (section 0), with the full flash size. The section is configured with full access key only, and without any plain access. This function requires running QLIB_SAFETY_Init before usage.

Parameters
[out]qlibContextQLIB internal state
[in]masterKeyMaster key value, array of 4 uint32_t (total of 128 bits). NULL or zero value key is not supported.
[in]sectionKeySection 0 key value, array of 4 uint32_t (total of 128 bits). NULL or zero value key is not supported.
Returns
QLIB_STATUS__OK = 0 - no error occurred
QLIB_STATUS__INVALID_PARAMETER - qlibContext is NULL
QLIB_STATUS__INVALID_PARAMETER - masterKey is NULL or zero value
QLIB_STATUS__INVALID_PARAMETER - sectionKey is NULL or zero value
QLIB_STATUS__SYSTEM_IN_INCORRECT_STATE - Flash device was not initialized. use QLIB_InitDevice
QLIB_STATUS__(ERROR) - Other error
Examples
qlib_sample_safety.c.

uint8_t *  buf_pu8,

uint32_t  size_u32 
)

This function safely reads data from the flash.

The data is read into buf_pu8 from offset.
This function requires running QLIB_SAFETY_Init before usage.

Parameters
[out]qlibContextQLIB internal state
[out]buf_pu8The data read
[in]offset_u32Section offset
[in]size_u32Size
Returns
QLIB_STATUS__OK = 0 - no error occurred
QLIB_STATUS__INVALID_PARAMETER - qlibContext is NULL
QLIB_STATUS__INVALID_PARAMETER - buf_pu8 is NULL
QLIB_STATUS__PARAMETER_OUT_OF_RANGE - size_u32 == 0 in case of standard read only
QLIB_STATUS__PARAMETER_OUT_OF_RANGE - offset_u32 + size_u32 > section size
QLIB_STATUS__SYSTEM_IN_INCORRECT_STATE - Flash device was not initialized. use QLIB_InitDevice or QLIB_ImportState
QLIB_STATUS__SYSTEM_IN_INCORRECT_STATE - Chip is not in working state
QLIB_STATUS__SYSTEM_IN_INCORRECT_STATE - Section is not enabled
QLIB_STATUS__(ERROR) - Other error

QLIB_API QLIB_STATUS_T QLIB_SAFETY_Erase ( QLIB_CONTEXT_T *  qlibContext,
uint32_t  offset_u32,
uint32_t  size_u32 
)

This function safely erases the given memory range.

The minimal memory range size is defined by QLIB_FLASH_SECTOR_SIZE. This function requires running QLIB_SAFETY_Init before usage.

Parameters
[out]qlibContextQLIB internal state
[in]offset_u32Section offset. The offset must be aligned to QLIB_FLASH_SECTOR_SIZE.
[in]size_u32Size. The size must be aligned to QLIB_FLASH_SECTOR_SIZE.
Returns
QLIB_STATUS__OK = 0 - no error occurred
QLIB_STATUS__INVALID_PARAMETER - qlibContext is NULL
QLIB_STATUS__INVALID_DATA_ALIGNMENT - offset_u32 is not aligned to sector size
QLIB_STATUS__INVALID_DATA_SIZE - size_u32 is not aligned to sector size
QLIB_STATUS__SYSTEM_IN_INCORRECT_STATE - Flash device was not initialized. use QLIB_InitDevice or QLIB_ImportState
QLIB_STATUS__SYSTEM_IN_INCORRECT_STATE - Chip is not in working state
QLIB_STATUS__PARAMETER_OUT_OF_RANGE - offset_u32 + size_u32 > section size
QLIB_STATUS__(ERROR) - Other error
Examples
qlib_sample_safety.c.
