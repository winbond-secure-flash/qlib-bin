End-to-end sample flow to calculate the KD1 pre-provisioned master key and use it to configure the device.

◆ QLIB_SAMPLE_KD1Config_provision()

QLIB_STATUS_T QLIB_SAMPLE_KD1Config_provision ( QLIB_CONTEXT_T *  ctx)

Provisions the device using a KD1-derived pre-provisioned master key. 

         Steps:
           - Derive KD1 from WID of die 0.
           - Configure the device using the calculated KD1:  a new deviceMasterKey, and configure a secure section.
           - Open a secure session to the section and verify secure access succeeds.
Parameters
[in]ctxQLIB context, already initialized and connected to the device
Returns
QLIB_STATUS__OK on success, QLIB_STATUS__(ERROR) otherwise
