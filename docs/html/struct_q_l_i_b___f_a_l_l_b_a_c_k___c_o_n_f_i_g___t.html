Detailed Description

This type contains specific DIE fallback mapping configuration.

It allows user to set different safe fallback configuration to each of the DIEs by setting FBIsPerDieConfig field in QLIB_DIE_CONFIG_T to true and setting specific DIE FB values in QLIB_FALLBACK_CONFIG_T struct.
