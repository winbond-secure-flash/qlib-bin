◆ QLIB_SAMPLE_LmsAttest_printStatus_L()

static QLIB_STATUS_T QLIB_SAMPLE_LmsAttest_printStatus_L ( QLIB_CONTEXT_T *  qlibContext,
const char *  stage_pc,
uint32_t *  leaf_pu32 
)
static

This routine prints which die is being attested and how many of its one-time keys are left.

Without it, an exhausted die fails with a bare QLIB_STATUS__SECURITY_ERR that looks indistinguishable from a real attestation failure.

Parameters
[in]qlibContextQLIB state object
[in]stage_pcname of the flow that is about to run, used as a log prefix
[out]leaf_pu32next leaf the die will sign with. May be NULL.
Returns
QLIB_STATUS__OK on success, or the status of the failed API
