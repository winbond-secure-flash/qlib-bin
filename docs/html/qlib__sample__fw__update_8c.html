Parameters

[in]buffSize_u32data buffer size in bytes
[in]section_u32Section index
[in,out]digestIntegrity_pu64If not NULL, section_u32 will be updated with digest, and copied here
[in,out]checksumIntegrity_pu32If not NULL, section_u32 will be updated with crc, and copied here
[in]newVersion_pu32Pointer to new version, if NULL no change will be set
