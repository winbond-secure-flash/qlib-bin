Sample Code Secure Storage

Secure storage sample demonstrates how to perform basic read/write/erase operations when using different section policies.
Two sections are used:

  1. A section which is configured as plain read access. Write and erase operations are secure.
  2. A section which is configured as fully secure (does not allow plain read or plain write access).

QLIB supports opening each section using a restricted access key and a full access key.
Basically, when opening a session with a restricted key, only a read operation is allowed. To use write or erase operations, a full access key must be used.
The section configuration is defined in the QLIB_POLICY_T structure.
