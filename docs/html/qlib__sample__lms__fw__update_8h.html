QLIB_STATUS_T QLIB_SAMPLE_LmsFwUpdate ( void *  userData_pv)

This function demonstrates LMS FW update usage with initialization sequence.

It is dependent on the results of the lms_tool.py Python script, as the buffer generate by this script is send to the flash in this sample.(when LMS_SAMPLE_PREPARE_IN_ADVANCE defined)
