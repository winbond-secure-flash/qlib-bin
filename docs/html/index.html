QLIB User-Guide

QLIB is a pre-compiled shared library by Winbond which provides an API to perform security-related W77Q operations and to deploy its advanced features. The QLIB library manages secret keys, cryptographic contexts, etc. needed for secure communication with W77Q/T.

Library Features

Included

  • All W77Q / W77T device support
  • Multi-die support (up to 4 dies)
  • Single SPI mode
  • Secure features (secure storage, attestation, FW update, watchdog, etc.)
  • Standard flash operations

See qlib.h for the full list of supported operations.
