QLIB_API QLIB_STATUS_T QLIB_InitDevice ( QLIB_CONTEXT_T *  qlibContext,
QLIB_BUS_FORMAT_T  busFormat 
)

This function initializes the communication with W77Q/T.

This function must be called before other QLIB API functions who communicate with W77Q/T
This function:

  1. Resumes and completes suspended erase/write operations.
  2. If the flash is in power down mode, the power down mode is released.
  3. If Multi-die chip includes flash with size over 128Mb, switch these dies to 4 bytes address mode.
    Parameters
    [out]qlibContextQLIB internal state
    [in]busFormatFlash interface format, consists of bus mode and dtr.
    Returns
    QLIB_STATUS__OK = 0 - no error occurred
    QLIB_STATUS__INVALID_PARAMETER - qlibContext is NULL
    QLIB_STATUS__DEVICE_SYSTEM_ERR - One of the sections has wrong configuration (e.g rollback and size is not correct)
    QLIB_STATUS__NOT_CONNECTED - Need to connect using QLIB_Connect function
    QLIB_STATUS__PARAMETER_OUT_OF_RANGE - busFormat is QLIB_BUS_MODE_4_4_4 and QLIB_SUPPORT_QPI is not defined
    QLIB_STATUS__NOT_SUPPORTED - QLIB_MAX_DIES_SUPPORTED doesn't support all dies detected on flash device
    QLIB_STATUS__(ERROR) - Other error

QLIB_API QLIB_STATUS_T QLIB_LoadKey ( QLIB_CONTEXT_T *  qlibContext,
uint32_t  sectionID_u32,
const KEY_T  key,
bool  fullAccess_b 
)

This function loads an access key used for QLIB secure operations.

This function loads restricted/full access keys of a section into QLIB. This key will be used in secure operations such as QLIB_OpenSession function.
There are two types of keys that can be configured: 'restricted access key' and 'full access key'. Each key has a different security properties.
The permissions configured are volatile and expire after flash reset or POR.

Parameters
[out]qlibContextQLIB internal state

This function should be used on a clean formatted flash in case it configures the keys.
In order to re-configure the flash keys, it need to be formatted with QLIB_Format function.
The 'restrictedKey' and 'fullAccessKey' of each section in cfgSectionArray can be empty keys (zero value). In such case the appropriate key locations will not be programmed to the chip, and remain un-programmed. Note: When the keys are un-programmed all related security operations are disabled.

This function perform QLIB maintenance.

In order to speed-up the time-critical boot sequence and session open process, QLIB maintenance is performed in iterations.
It is recommended to call QLIB_PerformMaintenance when the SW is in idle state.
It is recommended to call QLIB_PerformMaintenance only when maintenance is needed (QLIB_GetNotifications returns mcMaintenance bit 1).
Doing maintenance in idle time can save process time.
Recommended flow:

QLIB_NOTIFICATIONS_T notifications;
QLIB_STATUS_RET_CHECK(QLIB_GetNotifications(qlibContext, &notifications));
while (1u == notifications.mcMaintenance)
{
QLIB_STATUS_RET_CHECK(QLIB_PerformMaintenance(qlibContext));
QLIB_STATUS_RET_CHECK(QLIB_GetNotifications(qlibContext, &notifications));
}
