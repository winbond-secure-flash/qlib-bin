[SUM] Secure update mechanism

W77Q provides a fundamental contribution to the device's secure update mechanism (SUM) through its atomic firmware-update feature.

Firmware updates use a rollback section divided into active and inactive halves. The new firmware is written to the inactive half. Once writing is complete, a cryptographically protected swap command atomically exchanges the two halves. This allows the new firmware to be written gradually, including while the device is in a low-power state, while the final swap completes in a single operation. The swap command can use symmetric or asymmetric cryptographic protection.

Symmetric Cryptography

With symmetric cryptography, the section configuration command is issued during a secure session with the device. It is sent from the local or remote host to the connected W77Q target as an encrypted SPI transaction.

Asymmetric Cryptography

With asymmetric cryptography, a secure session with W77Q is not required. The host creates a section configuration string, potentially offline, and signs it with the private key of an LMS key pair. The host sends the string and its signature to W77Q. The device verifies the string using the LMS public key and, if verification succeeds, executes the configuration command.

Benefits and Drawbacks

Symmetric cryptography requires a secure session with the device, so each update flow is specific to that device. However, symmetric keys are straightforward to generate using the HKDF function.

Asymmetric cryptography does not require a secure session with the device. It supports broadcast updates by signing the section configuration string with a private key. However, generating an asymmetric key pair is more complex.

C code implementation

The update sample has manufacturing and field-use phases for both symmetric and asymmetric methods. During manufacturing, flash is configured with the required layout and policy: shared keys are configured for the symmetric method, while only the public LMS key is configured for the asymmetric method. The sample configures a rollback section and demonstrates both update methods.
